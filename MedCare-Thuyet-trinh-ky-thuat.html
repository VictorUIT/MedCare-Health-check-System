05 · Scheduling engine

Luồng tính khung giờ khả dụng

InputdoctorId
date=YYYY-MM-DD
→
Day mappingDate → dayOfWeek
mon ... sun
→
Generate slotsstart/end/duration
08:00 → 17:00
→
Filterbooked appointments
schedule blocks

Algorithm

schedule = findFirst({ doctorId, dayOfWeek, isAvailable })
slots = generateTimeSlots(start, end, duration)
blocks = findMany({ doctorId, date })
booked = appointments(PENDING|CONFIRMED|COMPLETED)
available = slots.map(slot => !booked && !blocked)

Output contract

{ date, dayOfWeek,
  isAvailableDay,
  workingHours,
  slots: [{ timeSlot,
    isAvailable,
    reasonNotAvailable }] }
Business invariant: một slot đã PENDING, CONFIRMED hoặc COMPLETED không được trả là khả dụng; lịch bận loại trừ theo khoảng thời gian.

09 · Technical conclusion

Đánh giá kỹ thuật và hướng mở rộng

Những gì hệ thống đã chứng minh

  • Luồng request được phân lớp từ UI đến database.
  • Business rule slot và state transition được kiểm soát.
  • Phân quyền theo role bảo vệ tài nguyên.
  • Schema quan hệ hỗ trợ mở rộng nghiệp vụ.
  • AI được cô lập trong service với fallback rule-based.

Hướng nâng cấp kiến trúc

  • Thêm Redis lock hoặc unique constraint cho cạnh tranh booking.
  • Queue gửi notification email/SMS.
  • OpenAPI/Swagger làm contract tự động.
  • CI pipeline: lint, test, build, deploy.
  • Observability: log correlation, metrics, tracing.
Layeredtách trách nhiệm
TypedTypeScript end-to-end
ValidatedYup + status code
Extensibledomain modules
Thông điệp kết luận: MedCare không chỉ là giao diện đặt lịch; đây là một workflow kỹ thuật hoàn chỉnh với boundary, contract, state machine và persistence rõ ràng.
